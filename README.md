# ERP to SCH

KiCad 原理图插件：把原理图里的元件按「数值 / 型号 + 封装」匹配到 ERP 原材料基础数据，
并把 **PartNumber** 与 **Description** 写回元件属性。

> 适用于 **KiCad 10.0.1 及以上**（IPC 插件，图标出现在原理图编辑器工具栏）。

---

## 支持的类别

| 类别 | 匹配依据 | 说明 |
|---|---|---|
| 贴片/插件电阻 | Value + 封装尺寸（`10K` + `0603`） | 支持 `4K7`、`4,7K`；毫欧写法 `26mR` / `26mΩ` / `0R026` 均识别为 0.026Ω |
| 贴片/插件电容 | Value + 封装尺寸（`100nF` + `0603`） | 按数值比较，`100nF`/`0.1uF` 等价 |
| 贴片/插件电感 | 感值 + 封装（`10uH/5A` + `1206`） | 额定电流不够的物料会被排除；`10uH`/`100nH`/`2m2H` 均可 |
| 贴片/插件晶振 | 频率 + 尺寸（`8MHz` + `3225`） | 支持 `MHz`/`kHz`；无源与有源晶振分开匹配 |
| 贴片/插件二极管 | 型号（`SS14`…） | **发光二极管 LED 不参与匹配** |
| 贴片/插件集成电路 | 型号（`LM358`…） | 型号一致 > 封装一致 > 库存 |
| 贴片/插件三极管 | 型号（`BC847C`…） | 同上 |
| 贴片/插件 MOS 管 | 型号（`AO3400A`…） | 同上 |
| 连接器 / 开关 / 存储器等 | 型号（只在候选唯一时自动选） | 详见下方“未分类元件” |

**贴片与插件严格区分**：`插件` 元件只匹配名称带“插件”的物料（或描述含 SMD/HC-49 等可判定字样），
不会把贴片料用到插件上（反之亦然）。

**只认电子物料料号**：搜索与自动匹配都只使用 **1 开头、正好 9 位** 的料号（如 `101010511`）；
`502010136` 这类成品料、13 位旧编码等一律不参与自动匹配。

其它元件（LED、可调/热敏电阻、包装材料等）仍会出现在列表里，可**手动搜索并指定物料**。

* **类别优先按库名判断**（`Connector:`/`Switch:` 等不会被当成芯片，`Device:R` 一定是电阻）；
* Value 为 `NC` / `DNP` / `DNF` / `DNI` 的元件显示 **不上件跳过**，不参与匹配也不会生成新料；
* `0Ω` 电阻会正常格式化（`贴片电阻,0603,0Ω,…`）。

### 写入范围

「写入原理图」右侧的 **写入范围 ▾** 可勾选要写入的类型：**已匹配 / 新料 / 手动修改**（默认全选）。
取消勾选后按钮会显示当前范围，只写入选中的类型。

### 品牌策略（仅电阻/电容）

**FH(风华) > 厚声 > YAGEO(国巨) > SUP（仅库存 > 0）> 新建 FH 新料**

* 禁用物料不参与匹配；
* SAMSUNG 等其它品牌不会自动选用（只在候选列表里展示）；
* 电阻 Value 没写容差时优先 ±5%，写了 `1%` 才优先 ±1%；
* 全部没有时按内置《物料参数要求表》的字段顺序生成新料，PartNumber 写 `新料`；
* **品牌只在新建电阻/电容时补 FH**，二极管、IC、三极管、MOS、LED、连接器等新料不写品牌；
* 写入的 `Description` / `PartNumber` 一律为**隐藏字段**（不会显示在原理图上）；
  若旧文件里的这两个字段原本是可见的，重新扫描并写入也会一并改成隐藏。

### 内置参数要求表（85 类全覆盖）

《物料参数要求表》整表已内置（`plugins/erp_rules_data.json`，共 **85 个类别**，
覆盖贴片/插件电阻、电容、电感、二极管、三极管、MOS、晶振、光耦、继电器、开关、
连接器、保险丝、蜂鸣器、显示屏、电池、电机、传感器等），不需要外部 Excel。

* 界面上的 **参数要求…** 按钮可直接查看全表（字段顺序 + 示例）；
* 右键 **生成新料描述…（可选类别）** 会弹出对话框：
  * 自动带入建议类别（按封装/型号猜，可手动改成任意一类）；
  * 对话框实时显示该类别的**字段顺序与示例**；
  * 描述自动填好后**仍可直接编辑**，再点“使用”写回列表；
* 类别不在表里的按通用规则 `料号名称、型号、尺寸、品牌` 生成。

## 安装

### 方式一：PCM 本地安装

```powershell
cd "d:\_LWH\KiCad Lib\Addons\ERP-To-SCH"
python package.py --install
```

然后在 KiCad：`插件和内容管理器 → 从文件安装… → erp-to-sch.zip`。

### 方式二：直接复制

把 `plugins/` 下的全部内容复制到：

```
C:\Users\<用户名>\Documents\KiCad\10.0\plugins\erp-to-sch\
```

（该目录下必须能直接看到 `plugin.json`。）

---

## ⚠️ 首次使用必须开启 API

`偏好设置 → 插件 → 启用 KiCad API（Enable KiCad API）`，然后重启 KiCad。

KiCad 会为该插件创建 Python 虚拟环境并安装 `requirements.txt` 里的依赖
（`kicad-python`、`xlrd`、`openpyxl`、`psutil`），首次可能需要几十秒。

## 使用

1. 打开原理图，点工具栏 **ERP 物料匹配**（或 `工具 → 外部插件`）；
2. 工程目录会自动定位到当前原理图所在目录（必要时可手动选择），并**自动扫描一次**（只读）；
3. **扫描**：只读取原理图当前内容（已有 PartNumber/描述 会原样列出来），不做任何修改；
4. **匹配**：按钮是**分割按钮**——左侧单击开始匹配，右侧小格 ▾ 弹出类别选择面板（勾选后不关闭，点外面或「关闭」才收起），默认全选；
   只处理还没有 PartNumber 的行，**已有数据的行一律不动**，不会被重复匹配覆盖；想单独重算某一行时，右键 **匹配此行（重新匹配）**；
5. 列表会列出工程内**全部元件**（按 **Value + 封装** 分组，相同元件只占一行、位号合并显示）：
   * 自动匹配成功的显示 PartNumber / 描述；
   * **双击单元格**（Value/型号、PartNumber、描述三列）→ 该格**就地变成输入框**直接改，
     `Enter` / 点别处 保存，`Esc` 取消；改 Value 写入时会一并写回原理图；
     需要一次改多项时仍可用右键「编辑内容…（弹窗）」；
   * 需要人工处理的（LED、连接器等）可点 **搜索物料…**，在 ERP 全表里按关键字搜索；
     默认**只搜电子物料**（料号 1 开头、9 位），可取消勾选看全部物料；
     搜索不区分全角/半角，支持表头点击排序（编码/名称/描述/品牌/库存/禁用）；
     右键搜索时会自动预填 **类别 + 封装 + Value**（如 `电阻 0603 10K`）；
   * 也可在 **选择候选…** 里查看该元件的所有候选（含品牌优先级与库存）；
   * 点击表头可排序（位号/类别/Value/封装/状态/PartNumber/描述/品牌/库存/候选）；
   * 右键菜单：**匹配此行**、搜索物料、查看候选、**生成新料描述…（可选类别）**、编辑内容、清除、复制位号；
6. 点 **写入原理图**（分割按钮：左侧写入，右侧 ▾ 选写入范围），先按 Ctrl+S 保存你手动改过的内容；
7. 插件会自动让 KiCad 重新加载原理图，无需关闭重开。

### 关于"自动重新加载"

KiCad 10 的原理图 IPC API 还不能修改图元，也没有"重新加载文档"命令
（原理图 API 到 KiCad 11 才有），`kicad-cli` 也无法操作已运行的界面。
因此插件采用：

1. 直接改写 `.kicad_sch` 文件（写前自动备份 `*.erp-bak`）；
2. 通过 Windows 消息向原理图窗口发送 `文件 → 放弃变更（Revert）`，
   并自动点击确认框里的「是」。

所以**写入后请不要再按 Ctrl+S**（那会用内存里的旧内容覆盖），
插件会在写入后直接帮你重新加载。

> 提示：中文版 KiCad 里这个菜单叫 **文件 → 放弃变更**。

## 配置

首次运行会在设置目录生成 `config.json`（`%APPDATA%\kicad-erp-to-sch\`）：

| 键 | 说明 |
|---|---|
| `erp_file` | ERP 物料表路径（.xls / .xlsx） |
| `preferred_brands` | 优选品牌顺序 |
| `fallback_brands` | 兜底品牌（需有库存） |
| `resistor_tolerance_priority` | 未标注容差时的优先顺序 |
| `resistor_power_by_size` | 新建电阻时按封装补的功率 |
| `capacitor_voltage_by_size` | 新建电容时按封装补的耐压 |
| `new_partnumber` | 新料的 PartNumber，默认 `新料` |

```

│   └── icons/
├── resources/icon.png
├── metadata.json
├── package.py
├── generate_icons.py
└── _dev/                    # 测试脚本
```

## 已知限制

* 只支持贴片元件（插件件、可调/热敏电阻不自动匹配）；
* 不匹配发光二极管（LED）；
* 品牌策略只针对电阻/电容，IC/三极管/MOS/二极管按型号选择（库存优先）。
